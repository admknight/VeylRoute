TorTunnel Universal v3.5.1 - Internal implementation files
==================================================================

Normal users should NOT run files in this folder directly.
Use ..\START-HERE.cmd, which provides the Control Center for Start, Status, Stop, app management, setup checks, help, and recovery.

The PowerShell scripts remain individually callable for advanced automation. They accept -Root so the portable TorTunnel root can live on any writable local drive/path.
