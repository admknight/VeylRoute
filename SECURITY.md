# Security policy

**Qualification candidate:** Windows v3.0 RC1 H5. No production-supported release has yet been declared.

VeylRoute modifies routing, DNS and firewall policies. For a bug report include the app and Windows versions, action, sanitized logs, and whether networking returned to its pre-session configuration. **Never post real bridge lines, Tor control cookies, personal IP addresses, credentials, private keys or private session logs.**

For a privacy/security vulnerability, use GitHub's private vulnerability reporting feature if enabled. Otherwise request a private contact route from the maintainer before sharing exploit details. A successful Tor exit-IP test does not establish comprehensive anonymity or DNS-leak containment.
