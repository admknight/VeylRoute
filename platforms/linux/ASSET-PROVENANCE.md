# VeylRoute Linux icon provenance

The five PNG assets under `assets/` are deterministic format exports of the **existing, approved VeylRoute Windows v3.0.1 ICO artwork** in `ui/assets/` from the published Windows portable package. No logo shape or text was redesigned. `veylroute.png` is an exact copy of `veylroute-disconnected.png` and is the freedesktop application icon. The four named states map to connected / connecting / disconnected / warning. The source ICO SHA-256 values are:

| State | SHA-256 of original Windows `.ico` |
| --- | --- |
| disconnected | `4ed0cc3a948218f674fa0cb1004577490b614d3dea93b2cca4947e600cdc533d` |
| connected | `d4fe3dd12d91b49be721c4f14740ab0c29aec67f407ab1f051ff5cf299c572f9` |
| connecting | `b50c9a0f08135825ffb1c2d904be346ad76bc2935fc98437b800be143e0d6654` |
| warning | `300984ae650bbfbfa20488f023f2fb1d77511eef2f046f7eb3ff4e6c2d484fbe` |

The original VeylRoute icon is maintained under the repository's project ownership and licensing terms; these derivative PNG assets are not third-party artwork.
