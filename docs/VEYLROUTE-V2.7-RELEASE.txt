VEYLROUTE CONTROL CENTER v2.7 PREVIEW — TRANSFER COMPLETION FIX
Engine baseline: TorTunnel Universal v3.5.1 (locked, unchanged).

CHANGES
- A missing, stale or mismatched component-progress.json can no longer leave the transfer bar in WORKING after the worker exits.
- The controller requires a fresh Completed record before claiming component-operation success.
- The hidden worker checks actual helper destination files against a fresh hash-bearing installation receipt.
- The background worker generates a failed terminal progress record when the component subprocess ends without one; no silent success.
- The progress writer uses bounded replace retries with a valid backup path so short Windows reader conflicts do not lose telemetry.
- HTTPS downloads now have shorter per-I/O wait limits and total transfer time limits. No partial archive is installed.
- On failure, the themed dialog guides the user to component setup and optional technical details.
- No routing, DNS, WFP, obfs4, engine start/stop/recovery, or configuration format changes.
