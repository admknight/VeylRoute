# Third-party components

VeylRoute orchestrates separate components; they are **not bundled** with repository-source artifacts.

| Component | Source |
| --- | --- |
| Tor Expert Bundle, lyrebird / obfs4 | https://www.torproject.org/ |
| Wintun | https://www.wintun.net/ |
| tun2socks | Upstream selected by the component provisioner |
| Inno Setup (build-only) | https://jrsoftware.org/isinfo.php |

Preserve original attribution, verify vendor signatures when supported by the provisioning workflow, and assess license compatibility before redistributing any third-party binaries. Referencing a project's URL is not permission to bundle its artifacts.
